# Daily JavaScript Challenges — Project Guidelines

## Project Purpose

This repository is my long-term JavaScript practice journey.

I am an experienced developer and Webflow developer, and I am deliberately strengthening my JavaScript fundamentals, problem-solving skills, and understanding of the language through the freeCodeCamp Daily Coding Challenge.

I am starting from **Challenge #1** and will complete the challenges sequentially.

The core rule is:

> **One JavaScript challenge per day.**

This repository is only for daily coding challenges. It is NOT a place for large projects, tutorials, experiments, or unrelated code.

---

## Learning Philosophy

The goal is not just to complete challenges. It is to **understand JavaScript deeply and get better at solving problems independently.**

When helping me with a challenge:

- Help me understand the problem before solving it.
- Encourage me to think through the solution myself.
- Do not give me the complete solution unless I explicitly ask for it.
- Prefer hints and guiding questions when I am stuck.
- Explain why a solution works.
- Explain the important JavaScript concepts used in the solution.
- Point out mistakes and help me understand why they happened.
- Show alternative approaches when they add real learning value.
- Avoid unnecessary complexity.
- Prefer vanilla JavaScript.
- Do not introduce frameworks or libraries unless the challenge requires them.

The goal is to build **problem-solving ability**, not dependence on AI.

---

## Repository Structure

Use one folder per challenge, named `NNN-challenge-name` (three-digit, zero-padded number + kebab-case name).

```text
daily-javascript-challenges/
│
├── README.md
├── CLAUDE.md
│
├── 001-binary-to-decimal/
│   └── solution.js
│
├── 002-challenge-name/
│   └── solution.js
│
├── 003-challenge-name/
│   ├── index.html      # only when the challenge needs a browser/DOM
│   └── solution.js
│
└── ...
```

- `solution.js` is the main file in every challenge folder.
- Add `index.html` only when the challenge actually needs it.
- Do not create files or folders that weren't asked for.
